## Implemented

Lower dock keeps Mixer and Sample Editor tabs in a shared header; existing Mixer body and common close remain. Double-click audio event body opens that event, makes the lower zone visible and selects Sample Editor. Double-click track label retains rename; gain-handle double-click retains unity reset. Tabs/selection are transient; editor target clears on new/open project, and missing/deleted targets show a message without stale edits.

Sample Editor has source waveform overview, time ruler, dense per-channel waveform, drag range selection, wheel zoom/fit, middle-button pan and shared source-position/trim/length/gain/fade parameter edits. Current ruler is seconds; full reference musical ruler, keyboard/pitch-axis/regions and audition/playhead synchronization are not yet implemented. AudioWarp/Pitch & Time are explicitly unavailable. No fake note rectangles or claimed correction. Source-unavailable and removed-event states render safely. Position/source trim are editable via fields in this slice; per-note movement and boundary stretching remain future work.

Held secondary-button toolbox is available on the Project audio grid and Sample Editor waveform: original vector cursor/scissors buttons select on hover, update the same toolbar EditTool and dismiss on release. Existing ruler and Track List context menus retain their separate targets. Scissors click splits at the common grid (or freely with snap off) and aligns cut to the nearest project sample. Split commands preserve source identity, offset, event gain and all original fade envelopes. Source WAVs are never rewritten/deleted.

Shift/Ctrl-click adds an audio event to the selection. With Project open and no text focus, X crossfades exactly two overlapping audio events on the same track. Chosen first-slice design: linear fade over existing overlap; no auto-extension, guessed overlap, cross-track pairing, contained/equal-start pairing or dialog. Invalid selection produces a status message. These choices are specified OpenTrack behavior; reference crossfade curve/dialog/ranges remain unmeasured. Multiple events are selected for crossfade; group drag is not implied.

Shared Project mutations flow through existing frame history/dirty/rebuild handling. Source-anchored fade lineage is bounded32 entries, validated and serialized with OPRv23; earlier native formats default empty and remain readable. It preserves the original envelope across cuts including within fades. New local fades multiply inherited fades; inherited envelope removal currently uses undo of the cut. Callback only evaluates bounded immutable fade data, with no additional file I/O/allocation. Waveforms apply the same inherited envelopes. Existing recording-file undo/discard source ownership is preserved.
