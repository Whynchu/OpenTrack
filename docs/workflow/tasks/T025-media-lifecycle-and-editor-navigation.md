## Implementation contract

Normal Delete removes selected audio events but retains source files and persistent pool entries. Clicking a track row clears event selection and separately targets that row (including MIDI/instrument content). It does not silently fall back to deleting a row after deleting an event; another row selection is needed. Shift/Ctrl event selection can remove multiple events. Shift+Delete removes target events/row plus unshared source paths/pool entries through reversible recovery. Files still referenced by an unselected event cause rejection of the whole operation before mutation, with a visible error window. Edit menu entries reflect Delete/Shift+Delete. Track context removal retains media too.

Project > Pool (Ctrl+P) shows persistent source paths, usage and missing-file state. Add to Project places retained audio at the shared transport into a compatible selected track or creates an appropriate audio track. It is undoable. This is a basic project pool, not full MediaBay indexing/preview/bulk conversion. OPRv24 persists the sorted unique pool; old loads register existing clips. Relinking updates pool paths too. Unreferenced decoded audio is still released; pool membership does not pin its waveform buffers in RAM.

History snapshots and file transactions are separate. Existing no-replace/preflight/rollback recovery is reused with the direction reversed for explicit deletion: Undo restores exact bytes/path before restoring project content; Redo removes again before returning the deleted project. Missing source/destination collisions block the action without advancing history. Recovery required by the saved project survives history trimming and redo-branch cleanup so discard can restore saved media. Unsaved-recording discard behavior remains intact. Undo is session-bound with the existing32-entry/128MiB snapshot budget; recovery occupies storage until history/finalized close can release it. Cache manifests remain as evidence after transfer/rollback errors; automatic crash-recovery UI is not implemented. No user project/media was operated on during implementation; file tests use generated temporary WAVs only.

Project Setup rate change now reads WAV headers for all pool/live media once on request. Mismatches or unavailable media trigger a confirmation listing old rates and offering Change Rate / Conform Playback or Cancel. No project rate change occurs before confirmation, and recording blocks request/application. Timing, pitch, duration, offsets and original WAV bytes stay intact; engine playback reads each source at its own rate and resamples to the active output clock. Project sample grid/new recordings use the selected project rate. This is explicit non-destructive playback conformity, not offline rewriting/resampling of WAV files and not automatic device-rate switching. The existing playback interpolator is used; high-quality offline band-limited file conversion remains separate. Sample rate/output driver rate and record encoding remain distinct settings. Rate changes are undoable; missing media remains offline and is reported.

Editor snap settings are independent application preferences, default Use Quantize/straight1/16, with enable, Grid Type and straight/triplet/dotted Quantize choices. They persist across target/project reset and app restart, outside project dirty state. Ruler release, cuts and selection ranges use editor snap; Project keeps its own settings. Event information columns are106px maximum, left aligned. Wheel zoom can exceed source length into empty timeline; middle pan works over waveform/empty area and ruler. Ruler horizontal seek and vertical zoom update simultaneously with anchored zoom; held-edge scrolling continues with repaint and elapsed frame time. Left edge is limited by project beat0. Fit/overview still refer to source extent. Source range drags keep the press-origin anchor rather than replacing it with the first movement point.

Scissors tool glyph is centered on the computed cut hotspot and native raw cursor hidden while a valid guide is active; grid snap does not leave the tool badge at the unsnapped pointer. Guide/commit still share sample alignment, and invalid endpoint cuts show no false guide. No additional pitch/time DSP or AudioWarp introduced; Rust and accepted Mixer/Project/recording behavior retained.
