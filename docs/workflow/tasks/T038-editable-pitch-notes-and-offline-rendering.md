## Implemented

- Corrected YIN baseline: 16 kHz analysis view, 96 ms window, 10 ms hop; 55-1600 Hz declared search range. Equal comparison length at all lags, first threshold trough rather than leading threshold crossing, and interpolation of the normalized difference. Low-rate sources interpolate missing bins instead of inserting zeros. The declared hop is sampling density, not a 10 ms accuracy guarantee for note boundaries.
- Separate deterministic voiced-note segmentation produces actual regions with stable IDs, source/destination boundaries and measured median pitch. The initial segmentation requires at least 50 ms of voiced frames. Unvoiced frames break the trace. Real vocal transitions, octave errors and deep vibrato still require qualification and repair tools.
- Colored region outlines, orange selection, editable curve preview; multi-selection, free pitch/time body drag, Shift fine pitch, independent editor-grid timing snap, left/right time stretch, scissors split, adjacent join, region removal, pitch quantize, straighten strength, reset, and source-boundary/center repair.
- Draft Undo/Redo groups pointer gestures and takes priority over project Undo in Sample Editor. **Apply pitch/time** renders and commits one normal undoable event edit. Pending drafts are explicitly labeled and remain session-only until Apply; switching the edited event currently discards an unapplied draft. Save the applied result before closing the project.
- Rust offline pitch-synchronous overlap-add worker; original source WAV is read-only. One channel's measured pulse locations are shared across channels to retain stereo balance/phase. The stronger source channel supplies pulse positions. Voiced edits have short boundary blends; surrounding time intervals interpolate between source/destination anchors. This is an initial monophonic renderer, not a qualified polyphonic or neural resynthesis engine.
- Atomic publication of separate float32 WAV variants under `Metadata/PitchTime`; playback and waveforms use the variant, including Project and Mixer routing. Original/corrected audition is available after Apply. Copies keep sharing their existing source/variant until individually edited. Export remains an existing separate gap.
- Source/range/detector identity and applied note edits/analysis persist in OPR v25 with defaults for older projects. Explicit analysis also writes an identity-keyed JSON mirror under `Metadata/Analysis`; embedded OPR data restores the editor without a new job. Independent events not already sharing an analyzed attachment do not yet consult that mirror to avoid duplicate analysis work.
- Jobs check source identity and event snapshot before publication; cancellation and editor changes cannot publish onto another event. Reanalysis is disabled while note drafts are pending. Source/range changes preserve saved intent and require explicit reanalysis for the changed range. Whole-source variants continue to support ordinary trim/split playback at source offsets. Missing variants retain intent and expose Apply to rebuild.
