# Tabler application assets

- Upstream: [tabler/tabler-icons](https://github.com/tabler/tabler-icons)
- Release: **v3.49.0**, tag commit **bbed884**
- License: MIT; full notice is in `LICENSE`.
- Vendor scope: 50 exact SVG assets listed below; no icon font or full-library dependency.
- Outline assets use 1.75-unit strokes, round caps, and round joins after toolbar contrast review. Filled player transport glyphs retain their conventional silhouettes.
- SVGs are parsed/rasterized by the centralized app icon registry on cache miss and cached by semantic ID, physical pixel size, and tint.
- The OpenTrack application mark is supplied by the user and is separate from Tabler assets.
